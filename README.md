# CUI Bus Online Frontend

Frontend application for CUI Bus Online built with React Native and Expo.

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn
- Expo Go app on iOS/Android (for testing on mobile)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/MuhammadGhayas1/cui-bus-online-frontend.git
   cd cui-bus-online-frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Setup environment variables:
   ```bash
   cp .env.example .env
   ```

4. Start the application:
   ```bash
   npx expo start
   ```
